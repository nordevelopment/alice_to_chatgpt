# Alice to ChatGPT (Яндекс.Алиса + OpenAI)

Вебхук для кастомного навыка Яндекс.Алисы, перенаправляющий запросы пользователей в OpenAI API (`gpt-4o`) с сохранением контекста беседы внутри сессии.

---

## 📋 Требования

* **PHP 8.1+** с расширениями `curl`, `json`, `mbstring`, `session`
* **Composer**
* **API-ключ OpenAI**
* **Публичный HTTPS-эндпоинт** (Яндекс Диалоги работают только по HTTPS)

---

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
composer install
```

### 2. Настройка окружения

Скопируйте файл конфигурации и укажите ваш ключ OpenAI:

```bash
cp .env.example .env
```

В файле `.env`:
```ini
OPENAI_API_KEY=sk-...your_openai_api_key...
```

### 3. Локальный запуск (для разработки и тестов)

Запустите встроенный PHP-сервер:

```bash
php -S 0.0.0.0:8000 index.php
```

Для проброса HTTPS-туннеля наружу используйте `ngrok` (или аналог):

```bash
ngrok http 8000
```

Скопируйте полученный HTTPS-адрес (например: `https://xxxx.ngrok-free.app`).

---

## 🛠️ Настройка в Яндекс Диалогах

1. Перейдите в консоль [Яндекс Диалогов](https://dialogs.yandex.ru/developer).
2. Нажмите **«Создать диалог»** → выберите **«Навык в Алисе»**.
3. Заполните основные настройки:
   * **Название навыка** и активационные фразы.
   * **Backend**: выберите **Webhook URL** и вставьте ваш HTTPS-адрес (например: `https://your-domain.com/index.php` или URL из ngrok).
4. Во вкладке **«Тестирование»** проверьте отправку реплик.
5. Нажмите **«Опубликовать»** (или используйте в приватном режиме для личных устройств).

---

## ⚙️ Особенности архитектуры

* **Контекст диалога**: хранится в рамках `session_id` Алисы через стандартный механизм `$_SESSION`.
* **Модель**: по умолчанию используется `gpt-4o` с таймаутом клиента 20 секунд.
* **Лимиты Яндекс Диалогов**: Яндекс ожидает ответ вебхука в течение **2.8–3 секунд**. Если генерация длинного ответа занимает больше времени, рассмотрите использование более быстрых моделей (`gpt-4o-mini`) либо стриминг/промежуточные ответы.
